# Difficult-frame collection

The web app saves user-confirmed failure examples here for a later model update.

- Original frames: `images/` (ignored by Git)
- Metadata: `manifest.jsonl` (ignored by Git)
- Initial status: `unannotated`

Review the manifest, upload selected images to Roboflow, annotate them manually,
and assign an entire related camera sequence to only one dataset split. Do not
move these images into the existing untouched test split.
